Encryption and Decryption Program

This project is a Python-based GUI application designed for text encryption and decryption using several classical cryptographic techniques.

Features

- Encrypt and decrypt text using the Caesar Cipher.
- Encrypt and decrypt text using the Vigenère Cipher.
- Encrypt and decrypt text using the Rail Fence Cipher.
- Use Brute Force to analyze Caesar Cipher encrypted text.
- Simple and user-friendly graphical interface.
- Built using Python.

Technologies Used

- Python
- GUI Development
- Classical Cryptography

Project Purpose

The purpose of this project is to demonstrate how different classical encryption techniques work and provide an easy-to-use graphical interface for encrypting and decrypting text.
